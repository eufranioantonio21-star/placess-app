# Project Brief: Placess Mobile App

## 1. Project Overview
**Placess** is a high-fidelity, immersive GPS navigation and discovery platform. It distinguishes itself through a stylized 3D isometric map environment (clay render style) and a game-inspired "Pro Dashboard" interface that balances professional utility with vibrant, playful aesthetics.

## 2. Target Audience
- **Urban Explorers:** Individuals looking for new cultural and social experiences (restaurants, coffee shops, cinemas).
- **Digital Flâneurs:** Users who appreciate high-end visual design and immersive interfaces while navigating.
- **Deal Seekers:** Consumers interested in live notifications and local business offers.

## 3. Visual Identity & Design System
The design has evolved through several iterations, settling on a sophisticated, illustrative, and professional aesthetic:
- **Core Theme:** "Vibrant Play" meet "Pro Dashboard."
- **Color Palette:** Deep navy, crisp white, and soft light blues, with signature purple and orange accents for interactive elements and highlights.
- **Typography:** Structured hierarchy with generous spacing (Plus Jakarta Sans / Inter).
- **Visual Style:** High-end clay renders for the 3D map, glassmorphism for UI overlays, and rounded-full components for a modern, friendly feel.

## 4. Key Features & Functionality
### A. Immersive 3D Map
- Central view featuring a beautiful 3D isometric city map.
- Stylized 3D markers for different categories (Food, Coffee, Museums, etc.).
- High-fidelity clay render style inspired by top-tier mobile simulation games.

### B. Pro Discovery & Navigation
- **Top Search Bar:** Floating, rounded search bar for quick location entry.
- **Extended Category Shelf:** A horizontally scrollable list above the main navigation for one-tap filtering of places like Restaurants, Coffee, Cinema, Pizza, and Parks.
- **Pull-up Discovery Sheet:** A swipable bottom sheet (Google Maps style) that reveals a list of nearby venues with rich details (ratings, distance, status).

### C. Live Notification System
- Dedicated **Live Offers** notification stream integrated into the interface.
- Distinct navigation for **Notifications** (deal stream) and **Alerts** (place-based warnings).
- Real-time business offers from the surrounding area.

### D. Dynamic Navigation Mode
- Tactical GPS navigation mode with a floating glassmorphic directions card.
- **Animated Guidance:** Directional arrows with pulse/glow effects.
- **Sequential Transitions:** Smooth slide-in/out animations for step-by-step instructions as the user moves.

## 5. Screen List (Current Progress)
1. **Main Map View:** The primary entry point featuring the 3D city and search.
2. **Explore Nearby (List View):** The pull-up sheet containing venue cards.
3. **Navigation Mode:** Active routing view with directional cards and tactical mini-map.
4. **Live Offers/Alerts:** Dedicated views for user notifications and business deals.

## 6. Future Roadmap
- **User Profiles:** Personalized explorer levels (e.g., "Pro Explorer").
- **Dark Mode Optimization:** Fully localized high-contrast "Vibrant Midnight" theme.
- **Social Discovery:** Sharing routes and "saved places" with friends.
